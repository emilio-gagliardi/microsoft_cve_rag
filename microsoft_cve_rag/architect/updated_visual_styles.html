Overview

KB5043355 is a Safe OS Dynamic Update released on September 10, 2024, aimed at enhancing the Windows recovery environment for various editions of Windows 11, version 24H2. The affected operating systems include:

  • Windows 11 SE, version 24H2
  • Windows 11 Enterprise and Education, version 24H2
  • Windows 11 Enterprise Multi-Session, version 24H2
  • Windows 11 Home and Pro, version 24H2
  • Windows 11 IoT Enterprise, version 24H2

This update specifically improves the functionality and reliability of the Windows Recovery Environment (WinRE). It replaces the previous update KB5041980 and does not require any prerequisites or device restarts after installation.

Technical Breakdown
Installation Process and Prerequisites

To install this update, administrators can utilize one of the following channels:

  • Windows Update: Automatically downloaded and installed.
  • Update Catalog: Standalone package available for manual download. Refer to Microsoft Update Catalog.
  • Server Update Services (WSUS): This update will sync automatically if configured with:
  • Product: Windows 11
  • Classification: Security Updates

There are no prerequisites for applying this update. Additionally, it cannot be removed once applied to a Windows image.

Methods to Verify WinRE Version Installed

To verify the installed version of WinRE post-update, several methods can be employed:

  1. PowerShell Script: Use the provided GetWinREVersion.ps1 script with Administrator credentials to retrieve the WinRE version. (powershell # PowerShell script content omitted for brevity; see full script in KB article).
  2. DISM Command: Run the following command in an elevated command prompt to get WinRE information: 
    cmd dism /Get-ImageInfo /ImageFile:\\?\GLOBALROOT\device\harddisk0\partition$\Recovery\WindowsRE\winre.wim /index:1
  3. Event Viewer: Check for servicing events related to WinREAgent by navigating through:
  4. Open Event Viewer > Expand Windows Logs > Click System > Search for "WinREAgent".
  5. Look for Event ID: 4501 indicating servicing success.
Vulnerabilities and Bug Fixes

The update primarily focuses on improvements rather than addressing specific vulnerabilities or bugs. However, it enhances overall system recovery capabilities within the affected versions of Windows.

Verification of Installation

After installation, confirm that the installed WinRE version is 10.0.26100.1710. This can be done using any of the verification methods outlined above.

Removal Information

As stated earlier, this update cannot be removed once applied to a Windows image.

Overview

KB5043939 is an update released on September 10, 2024, aimed at enhancing the Out-of-Box Experience (OOBE) for Windows 11, version 24H2. This update specifically targets the OOBE process and is applicable only when OOBE updates are installed. The affected operating systems include:

  • Windows 11 SE, version 24H2
  • Windows 11 Enterprise and Education, version 24H2
  • Windows 11 Enterprise Multi-Session, version 24H2
  • Windows 11 Home and Pro, version 24H2
  • Windows 11 IoT Enterprise, version 24H2

The update does not replace any previously released updates and requires a device restart post-installation. There are no prerequisites for this update.

Technical Breakdown
Vulnerabilities and Bug Fixes

This section outlines the improvements made in KB5043939:

  • Improvement to OOBE Process: Enhances the overall user experience during the initial setup of Windows 11 by streamlining processes and ensuring smoother transitions.
  • Type: Improvement
  • Affected Component: Out-of-Box Experience (OOBE)
Installation Process and Prerequisites

To install this update:

  1. Ensure that your device is connected to the internet during the OOBE process.
  2. The update will be automatically applied if OOBE updates are enabled.
  3. After installation, a system restart is required to complete the update process.

Preferred channels for receiving this update include:

  • Windows Update: Automatic installation during OOBE.
  • Autopatch: For organizations utilizing Microsoft Intune for device management.

There are no uninstallation instructions provided as this update is integral to the OOBE process.
